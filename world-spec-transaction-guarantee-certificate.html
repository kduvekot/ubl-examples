Guarantee certificate

Transaction of the Trade Accord in the UBL example world · all specifications

Identifier: urn:ubl-examples:world:trns:guarantee-certificate:1.0

One document type carries the transaction, the Guarantee Certificate, which UBL 2.5 defines as follows: “A document to notify the deposit of a Guarantee, such as a bid bond.”

Owner: Lumeport Trade Accord Council. Version 1.0.
