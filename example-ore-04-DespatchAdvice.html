Despatch Advice: Serravona Mining to Valdara Industries

Example 4 of the flow "Ore from the mine to the factory (domestic, Urvania)" · Despatch Advice in the UBL 2.5 specification

The mine announces what was loaded into which wagons, so the factory can plan the unloading.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5 (world/ubl-versions.json); Party/AdditionalPartyIdentification first appears in UBL 2.5.
  • CustomizationID = urn:ubl-examples:world:trns:despatch-advice:1.0
    The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Despatch advice". Each has a public description on the world's pages (world/specifications.json).
  • ProfileID = urn:ubl-examples:world:profile:despatch-receipt:1.0
    The Trade Accord's process profile the document belongs to: despatch and receipt, a generic, versioned profile, not the flow; the run of the process is the ProfileExecutionID.
  • ProfileExecutionID = ORE-2026-01
    This run of the process: the same in every document of the flow.
  • ID = SM-DA-26-0308
    The despatching party's number.
  • UUID = e3281a6d-51f4-5981-b7f0-b43b6a9cf2da
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
  • IssueDate = 2026-03-10
    The day the train was loaded and weighed.
  • IssueTime = 10:20:00-01:00
    Sent once the train has left the siding at 10:05, so that the factory can plan the unloading before it arrives; in the issuer's local time, with its offset from UTC (D27).
  • DespatchAdviceTypeCode = DELIVERY (listID urn:ubl-examples:world:codelist:DespatchAdviceTypeCode)
    Advice of goods despatched for delivery. The code is from the Trade Accord's despatch advice type list: DELIVERY = Delivery.
  • Note = Gannek kikran drek valnir rek marsir stan skuskek ran muhir rek drek silsan mek. (languageID qau)
    The note in Urvanian, the sender's language (world/countries.json): What the receiver should do; the note names the transport document the flow uses (worklist C30).
  • Note = Please check the goods on arrival and report any damage on the consignment note. (languageID en-XU)
    The same note in English, the working language between the countries: What the receiver should do; the note names the transport document the flow uses (worklist C30).
