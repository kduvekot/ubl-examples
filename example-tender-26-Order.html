Order: Lumeport Public Works Department to Valdara Industries

Example 26 of the flow "A public tender (Bayvarra)" · Order in the UBL 2.5 specification

The first call-off under the awarded contract. Delivery terms DAP the authority's site: the manufacturer delivers, by the road carrier it chooses.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5 (world/ubl-versions.json); Party/ElectronicAddress first appears in UBL 2.5.
  • CustomizationID = urn:ubl-examples:world:trns:order:1.0
    The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Order". Each has a public description on the world's pages (world/specifications.json).
  • ProfileID = urn:ubl-examples:world:profile:ordering:1.0
    The Trade Accord's process profile the document belongs to: ordering, a generic, versioned profile, not the flow; the run of the process is the ProfileExecutionID.
  • ProfileExecutionID = TENDER-2026-01
    This run of the process: the same in every document of the flow.
  • ID = LPWD-PO-26-0212
    The buyer's order number.
  • UUID = 9865133f-cea3-538c-ba26-54de8100727c
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
  • IssueDate = 2026-03-23
    The first call-off under the awarded contract.
  • IssueTime = 14:40:00-01:00
    The time the sender's system issued the document, in the sender's local time; in the issuer's local time, with its offset from UTC (D27).
  • OrderTypeCode = 220 (listID UN/EDIFACT EDED 1001)
    UN/EDIFACT 1001 code 220: order. The code is from the world's copy of UN/EDIFACT 1001 Document name: 220 = Order.
  • Note = Release 1 under the framework contract: 40 of the 240 benches.
    Which call-off this is; Delivery/ReleaseID is an access approval at the delivery place, not a call-off number (tender/26#F5).
  • DocumentCurrencyCode = XBL (listID ISO 4217 Alpha)
    The lume, the buyer's currency, agreed in the contract; it has two decimals. The code is from the world's copy of UBL's Currency (ISO 4217) list: XBL = Lume.
  • TaxCurrencyCode = XUF (listID ISO 4217 Alpha)
    The manufacturer accounts its value added tax in ferra. The code is from the world's copy of UBL's Currency (ISO 4217) list: XUF = Ferra.
  • AccountingCostCode = PWD-PARKS-26
    The buyer's cost centre, to be quoted on the invoice.
  • AccountingCost = Parks renewal programme 2026
    The cost centre in words.
  • LineCountNumeric = 1
    The number of order lines.
