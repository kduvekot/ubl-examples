Code lists

The code lists the documents of the world use, each published as a genericode file at the address its documents give. Where a document uses a real external list (UN/EDIFACT, ISO, the WCO's Harmonized System and others), the world's file holds the codes it uses, with the list's own identifier; the Trade Accord's and the countries' own lists are the world's. The context/value association binds each code element of UBL 2.5 to its list, as UBL's own validation does.

The lists of countries and currencies extend UBL's default lists of version 2.4 with the codes of the world's three countries and their currencies.
