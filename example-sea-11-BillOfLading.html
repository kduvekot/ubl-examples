Bill of Lading: Tidewell Ocean Lines to Bayforth Forwarding

Example 11 of the flow "Overseas by container ship, cost insurance and freight (Bayvarra → island Lisavu)" · Bill of Lading in the UBL 2.5 specification

The negotiable bill of lading, issued to the forwarder that gave the instructions; it names the insurer of the cargo and the buyer's 3PL as party to notify on arrival.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The documents of the world use UBL 2.5.
  • CustomizationID = urn:ubl-examples:world
    The example world is a customization of UBL: it uses its own code lists for countries and currencies.
  • ID = TOL-BL-26-0136
    The bill of lading number.
  • IssueDate = 2026-05-14
    Issued when the goods are shipped on board.
