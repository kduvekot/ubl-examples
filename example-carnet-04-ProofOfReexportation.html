Proof of Reexportation: Ferrano Chamber of Commerce to Selanu Chamber of Commerce

Example 4 of the flow "Samples to a trade fair on the island (temporary export)" · Proof of Reexportation in the UBL 2.5 specification

Urvania's chamber proves the samples were re-exported: they came home through Urvania's customs.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5 (world/ubl-versions.json); Party/ElectronicAddress first appears in UBL 2.5.
  • CustomizationID = urn:ubl-examples:world:trns:proof-of-reexportation:1.0
    The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Proof of re-exportation". Each has a public description on the world's pages (world/specifications.json).
  • ProfileID = urn:ubl-examples:world:profile:temporary-admission:1.0
    The Trade Accord's process profile the document belongs to: temporary admission, a generic, versioned profile, not the flow; the run of the process is the ProfileExecutionID.
  • ProfileExecutionID = CARNET-2026-01
    This run of the process: the same in every document of the flow.
  • ID = FCC-DOC-26-0728
    The sender's number for this document.
  • UUID = a5be84f0-33dc-58b3-97e4-10dea98880ab
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
  • IssueDate = 2026-08-28
    Urvania's chamber answers with the proof.
  • IssueTime = 13:19:00
    The time the sender's system issued the document, in the sender's local time.
  • Note = Drek barhek tan hek rek drek san sturvan. (languageID qau)
    The note in Urvanian, the sender's language (world/countries.json): The proof.
  • Note = The samples came home on the date stamped. (languageID en-XU)
    The same note in English, the working language between the countries: The proof.
  • VersionID = 1
    The first version.
