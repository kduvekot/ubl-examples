Retail event

Transaction of the Trade Accord in the UBL example world · all specifications

Identifier: urn:ubl-examples:world:trns:retail-event:1.0

One document type carries the transaction, the Retail Event, which UBL 2.5 defines as follows: “A document used to specify basic information about retail events (such as promotions, product introductions, and community or environmental events) that affect supply or demand.”

Owner: Lumeport Trade Accord Council. Version 1.0.

Document types: RetailEvent.
