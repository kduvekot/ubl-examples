# Party cover: the organisations the UBL example world needs

Every party element in every UBL 2.5 document type is assigned an organisation
type, based on its UBL definition in its context. Generated by
`tools/party_cover.py` from `UBL-Entities-2.5.gc`; the mapping table is in the script.

## Summary

- **Organisation types needed (full cover):** 27, listed below.
- **Most organisations one document needs, document level:** 6 (GoodsCertificate).
- **… including one structure level deeper** (delivery, shipment, tendering terms): 7 (GoodsItemItinerary).
- **… including every party element a document can contain:** 20 (Tender, TendererQualification).

## Merging types: the smallest world

Some types can be one organisation in practice. A merge is only possible if
no document needs both types (checked at document level and one structure
level deeper); otherwise one organisation would appear twice in that document.

| Merge | Why it can be one organisation | Conflict |
|---|---|---|
| Manufacturer → Seller | The seller makes what it sells. | not possible, both needed in InstructionForReturns, WasteMovement, WasteNotification |
| Utility supplier → Seller | A utility is a seller of energy, water or telecom services. | none: merge possible |
| Warehouse / goods processing → Freight forwarder / logistics operator | A logistics operator also runs warehouses. | not possible, both needed in GoodsCertificate |
| Customs agent / declarant → Freight forwarder / logistics operator | Forwarders commonly act as customs agent. | none: merge possible |
| Insurance broker → Freight forwarder / logistics operator | Forwarders commonly arrange cargo insurance. | none: merge possible |
| Tax representative → Freight forwarder / logistics operator | Forwarders and customs agents commonly act as fiscal representative. | none: merge possible |
| Port, terminal or weighing operator → Carrier | A carrier can operate its own terminal. | not possible, both needed in CommonTransportationReport |
| Insurer → Bank / financial institution | One financial group can provide both finance and insurance. | none: merge possible |
| Identifier issuing agency → Certifying body | A chamber of commerce or trade association can issue identifiers. | none: merge possible |
| Governance body of a digital agreement → Public information service | A public service can govern a digital agreement framework. | none: merge possible |
| Review body → Public information service | A public body can handle procurement appeals. | none: merge possible |
| Other government authority → Customs authority | One government administration for customs and certification. | none: merge possible |
| Economic operator → Seller | In procurement, the tenderer is the seller. | none: merge possible |
| Waste processor → Seller | A waste processor sells its processing service. | not possible, both needed in WasteMovement, WasteNotification |

**Smallest world:** 17 organisations, after the possible merges above:
Buyer, Seller, Manufacturer, Contracting authority, Second economic operator, Public information service, Freight forwarder / logistics operator, Carrier, Second carrier, Warehouse / goods processing, Port, terminal or weighing operator, Customs authority, Second customs authority, Certifying body, Second certifying body, Bank / financial institution, Waste processor.

## Compared with the 26+C party set

Types that the documents need but that have no counterpart in the 26+C set
(`analysis/session-decisions.md` on branch `sample-research`, section 5.3):

- Second economic operator (consortium partner, subcontractor)
- Review body (procurement appeals and mediation) (can merge into Public information service)
- Other government authority (flag state, certifying ministry) (can merge into Customs authority)
- Insurer (can merge into Bank / financial institution)
- Insurance broker (can merge into Freight forwarder / logistics operator)
- Tax representative (can merge into Freight forwarder / logistics operator)
- Governance body of a digital agreement (can merge into Public information service)
- Identifier issuing agency (item or property identifiers) (can merge into Certifying body)
