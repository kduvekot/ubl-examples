Invoice: Selanu Cotton Ginnery to Lumeport Textile Mill

Example 14 of the flow "Cotton: from the island's farms to the textile mill (Lisavu → Bayvarra)" · Invoice in the UBL 2.5 specification

The bales, free on board. No tax applies on the island, and the invoice says so.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The documents of the world use UBL 2.5.
  • CustomizationID = urn:ubl-examples:world
    The example world is a customization of UBL: it uses its own code lists for countries and currencies.
  • ProfileID = urn:ubl-examples:world:process:cotton
    The business process the document belongs to: the flow "Cotton: from the island's farms to the textile mill (Lisavu → Bayvarra)".
  • ProfileExecutionID = COTTON-2026-01
    This run of the process: the same in every document of the flow.
  • ID = SCG-INV-26-0207
    The seller's invoice number.
  • UUID = 4f18c6ce-24a6-56a3-a394-583665232c05
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
  • IssueDate = 2026-03-02
    Issued when the bales are on board.
  • IssueTime = 11:22:00
    The time the sender's system issued the document, in the sender's local time.
  • DueDate = 2026-04-01
    30 days after the issue date, the agreed payment term.
  • InvoiceTypeCode = 380
    UN/EDIFACT 1001 code 380: commercial invoice.
  • DocumentCurrencyCode = XLC
    The coral, the seller's currency; it has three decimals.
  • PaymentCurrencyCode = XLC
    Payment is asked in the invoice currency, also from abroad.
  • AccountingCostCode = 2200
    The buyer's cost centre, quoted in its order, so the invoice is booked without asking.
  • AccountingCost = Raw cotton
    The cost centre in words.
  • LineCountNumeric = 1
    The number of invoice lines, as a check on the transfer.
  • DefaultLanguageCode = en
    The language of the texts that carry no language identifier: English, the working language between the countries; a seller from Urvania or the island also gives its notes in its own language.
