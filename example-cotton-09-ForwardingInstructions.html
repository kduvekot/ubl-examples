Forwarding Instructions: Lumeport Textile Mill to Bayforth Forwarding

Example 9 of the flow "Cotton: from the island's farms to the textile mill (Lisavu → Bayvarra)" · Forwarding Instructions in the UBL 2.5 specification

Under FOB the buyer books the main carriage: the mill instructs its forwarder.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5 (world/ubl-versions.json); Party/AdditionalPartyIdentification first appears in UBL 2.5.
  • CustomizationID = urn:ubl-examples:world:trns:forwarding-instructions:1.0#compliant#urn:ubl-examples:world:community:port-lumeport:1.0
    The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Forwarding instructions"; the community specification "Lumeport port community". Each has a public description on the world's pages (world/specifications.json).
  • ProfileID = urn:ubl-examples:world:profile:transport:1.0
    The Trade Accord's process profile the document belongs to: transport, a generic, versioned profile, not the flow; the run of the process is the ProfileExecutionID.

    This run of the process: the same in every document of the flow.
  • ID = LTM-FI-26-0199
    The mill's instruction number.

    In words.
