#30 Maritime Administration

Country C (XC) · Government · proposed addition to the 26+C set

The island's flag state administration; issues ship security certificates.

How UBL helps

The island's maritime administration issues ship security certificates. UBL transport reports to the port carry the certificate and its issuer, so the port can check them before the ship arrives.
