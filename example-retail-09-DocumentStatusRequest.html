The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5; Party/AdditionalPartyIdentification first appears in UBL 2.5.
  • CustomizationID = urn:ubl-examples:world:trns:order-status:1.0#compliant#urn:ubl-examples:world:community:retail:1.0
    The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Order status"; the community specification "Retail community". Each has a public description on the world's pages.
  • ProfileID = urn:ubl-examples:world:profile:ordering:1.0
    The Trade Accord's process profile the document belongs to: ordering, a generic, versioned profile, not the flow.
  • ProfileExecutionID = 9900339316
    The collaboration this document belongs to: the store's order from Lumeway, from the order to the credit note. Brightmarket Stores started it and gave it this identifier, which every document of it repeats.
  • ID = 6600016979
    The sender's number for this document.
  • UUID = 44994824-762c-5e0e-a7c5-0010d1f4141f
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
  • IssueDate = 2026-04-27
    Asked on Monday 27 April, the first working day after the order of Friday 24 April.
  • IssueTime = 11:00:00-01:00
    In the late morning; in the issuer's local time, with its offset from UTC.
  • Note = Has the order been accepted?
    The question.
  • TrackingID = 7100452422
    The order the store tracks.

Sender Party

Inside SenderParty:

The party's own data, as Brightmarket Stores gives it (15 values)
  • PartyIdentification/ID = 20410411 (schemeID urn:ubl-examples:world:XB:register)
    The party's preferred identifier: its number in the Federal business register of Bayvarra. Later mentions of the same party in this document repeat only this identifier and the name.
  • AdditionalPartyIdentification/ID = 9522610900002 (schemeID GS1 GLN)
    A further identifier, the party's Global Location Number (the endorsed PartyIdentification holds one only): it identifies itself, its items and its places the GS1 way, under its company prefix, which starts with 952, the prefix GS1 reserves for examples .
  • PartyName/Name = Brightmarket Stores
    The trading name.
  • Language/ID = en (schemeID ISO 639)
    English, the language the party writes in this document. The code is from the world's copy of ISO 639 Language: en = English. An identifier that holds a code names the code's list in its schemeID.
  • Language/Name = English
    The language's name.
  • Language/LocaleCode = en-XB (listID urn:ubl-examples:world:codelist:LocaleCode)
    The English the party writes: the variety of Bayvarra, with the country as the region; English is used in all three countries, so its locale says which. The code is from the Trade Accord's locale list: en-XB = Bayvarran English.
  • Contact/ID = BM-CT-01
    The desk's number in the party's own contact list.
  • Contact/Name = Buying office
    The party's main desk, which handles this document.
  • Contact/JobTitle = Buyer
    The job of the person who answers at the desk.
  • Contact/Department = Purchasing
    The department the desk belongs to.
  • Contact/Telephone = +999 2 38 4609 7100
    Telephone under +999, a country code the ITU reserves for a future global service (ITU-T E.164), so the number reaches no one; then the country digit and a number in Bayvarra's own plan: British-style closed numbering: always 10 digits after the country digit; the area code takes 2 to 5 of them (Lumeport 38, Upland State 7121, Gullhaven 38522 in the Northern Territory: the plan is national and does not follow state borders) and the trunk prefix 0 is dropped from abroad. Mobiles start with 7.
  • Contact/ElectronicMail = buying@brightmarket.example
    E-mail under the reserved .example domain (RFC 2606), so it cannot reach anyone.
  • Contact/Note = Monday to Saturday 09:00–18:00
    When the desk can be reached.
  • ElectronicAddress/ExchangeNetworkID = urn:ubl-examples:world:network
    The network in which the address is registered: the world's own exchange network.
  • ElectronicAddress/ElectronicAddressID = XB:20410411 (schemeID urn:ubl-examples:world:endpoint)
    The party's electronic address in that network: its country code and its number in the Federal business register of Bayvarra. UBL 2.5 carries it here; Party/EndpointID is deprecated.

The same in every document Brightmarket Stores is named in.

  • TradePartyName/Name = Brightmarket
    The name the shops trade under, shorter than the company's name; as Brightmarket Stores gives it.
