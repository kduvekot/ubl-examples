Delivery Note: Lisavu Cotton Farm to Selanu Cotton Ginnery

Example 2 of the flow "Cotton: from the island's farms to the textile mill (Lisavu → Bayvarra)" · Delivery Note in the UBL 2.5 specification

The farm delivers a trailer of seed cotton at the gin and confirms what it delivered.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The documents of the world use UBL 2.5.
  • CustomizationID = urn:ubl-examples:world
    The example world is a customization of UBL: it uses its own code lists for countries and currencies.
  • ID = LCF-DN-26-0192
    The farm's delivery note number.
  • IssueDate = 2026-02-05
    The day the trailers were weighed at the gin.
