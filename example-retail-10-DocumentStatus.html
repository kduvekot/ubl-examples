Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5; Party/AdditionalPartyIdentification first appears in UBL 2.5.
  • CustomizationID = urn:ubl-examples:world:trns:order-status:1.0#compliant#urn:ubl-examples:world:community:retail:1.0
    The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Order status"; the community specification "Retail community". Each has a public description on the world's pages.
  • ProfileID = urn:ubl-examples:world:profile:ordering:1.0
    The Trade Accord's process profile the document belongs to: ordering, a generic, versioned profile, not the flow.
  • ProfileExecutionID = 9900339320
    The collaboration this document belongs to: the store's order from Lumeway, from the order to the credit note. Brightmarket Stores started it and gave it this identifier, which every document of it repeats.
  • ID = LMW-DST-26-0045
    The sender's number for this document.
  • UUID = eb9072fe-2cf3-54f8-bb18-08f7f9930b9c
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
  • IssueDate = 2026-04-27
    Answered the same day.
  • IssueTime = 11:20:00-01:00
    After the carrier had confirmed the truck; in the issuer's local time, with its offset from UTC.
  • Note = Accepted; the truck is booked for a delivery on 30 April.
    The answer.

  • Language/LocaleCode = en-XB (listID urn:ubl-examples:world:codelist:LocaleCode)
    The English the party writes: the variety of Bayvarra, with the country as the region; English is used in all three countries, so its locale says which. The code is from the Trade Accord's locale list: en-XB = Bayvarran English.
  • Contact/Name = Sales office
    The party's sales office desk: the desk for its role in this document (it sells).
  • Contact/JobTitle = Sales coordinator
    The job of the person who answers at the desk.
  • Contact/Department = Sales
    The department the desk belongs to.
  • Contact/Telephone = +999 2 7121 955 964
    The party's switchboard, which puts the caller through to the desk. Telephone under +999, a country code the ITU reserves for a future global service (ITU-T E.164), so the number reaches no one; then the country digit and a number in Bayvarra's own plan: British-style closed numbering: always 10 digits after the country digit; the area code takes 2 to 5 of them (Lumeport 38, Upland State 7121, Gullhaven 38522 in the Northern Territory: the plan is national and does not follow state borders) and the trunk prefix 0 is dropped from abroad. Mobiles start with 7.
  • Contact/ElectronicMail = sales@lumeway.example
    E-mail under the reserved .example domain (RFC 2606), so it cannot reach anyone.
  • Contact/Note = Weekdays 08:00–17:00
    When the desk can be reached.
  • ElectronicAddress/ExchangeNetworkID = urn:ubl-examples:world:network
    The network in which the address is registered: the world's own exchange network.
  • ElectronicAddress/ElectronicAddressID = XB:20410274 (schemeID urn:ubl-examples:world:endpoint)
    The party's electronic address in that network: its country code and its number in the Federal business register of Bayvarra. UBL 2.5 carries it here; Party/EndpointID is deprecated.
