Proof of Reexportation Request: Selanu Chamber of Commerce to Ferrano Chamber of Commerce

Example 2 of the flow "Samples to a trade fair on the island (temporary export)" · Proof of Reexportation Request in the UBL 2.5 specification

The island's chamber has no re-export stamp for the samples and asks for proof that they left.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The documents of the world use UBL 2.5.
  • CustomizationID = urn:ubl-examples:world
    The example world is a customization of UBL: it uses its own code lists for countries and currencies.
  • ProfileID = urn:ubl-examples:world:process:carnet
    The business process the document belongs to: the flow "Samples to a trade fair on the island (temporary export)".
  • ProfileExecutionID = CARNET-2026-01
    This run of the process: the same in every document of the flow.
  • ID = SCC-DOC-26-0726
    The sender's number for this document.
  • UUID = 3377b749-219b-5bbb-a9d2-7d1101bcbe28
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
  • IssueDate = 2026-07-24
    Two months after the fair the samples' re-export is not recorded.
  • IssueTime = 08:50:00
    The time the sender's system issued the document, in the sender's local time.
  • Note = The island's customs found no re-export stamp.
    Why the chamber asks.
  • VersionID = 1
    The first request.
  • GoodsItemPassportID = FCC-DOC-26-0724
    The carnet the samples travelled under.
  • GoodsItemPassportCounterfoilID = IMP-1
    The importation counterfoil without a re-export.
