Catalogue: Valdara Industries to Lumeport Public Works Department

Example 25 of the flow "A public tender (Bayvarra)" · Catalogue in the UBL 2.5 specification

The framework contract is ordered from a catalogue: the manufacturer publishes the awarded items and prices, each line pointing to the call for tenders.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.
