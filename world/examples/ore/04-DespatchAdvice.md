# Despatch Advice: Serravona Mining to Valdara Industries

*Example 4 of the flow "Ore from the mine to the factory (domestic, Urvania)" · [Despatch Advice in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-DESPATCH-ADVICE-SCHEMA)*

The mine announces what was loaded into which wagons, so the factory can plan the unloading.

[The XML file](04-DespatchAdvice.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.
