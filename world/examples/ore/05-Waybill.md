# Waybill: Ferrano Rail Cargo to Valdara Industries

*Example 5 of the flow "Ore from the mine to the factory (domestic, Urvania)" · [Waybill in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-WAYBILL-SCHEMA)*

The rail consignment note goes to the party that contracted the carriage, the manufacturer; the mine is named as consignor because the ore is loaded there.

[The XML file](05-Waybill.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

### The document itself

- `UBLVersionID` = **2.5**  
  The documents of the world use UBL 2.5.
- `CustomizationID` = **urn:ubl-examples:world**  
  The example world is a customization of UBL: it uses its own code lists for countries and currencies.
- `ProfileID` = **urn:ubl-examples:world:process:ore**  
  The business process the document belongs to: the flow "Ore from the mine to the factory (domestic, Urvania)".
- `ProfileExecutionID` = **ORE-2026-01**  
  This run of the process: the same in every document of the flow.
- `ID` = **FRC-WB-26-0310**  
  The consignment note number.
- `CarrierAssignedID` = **FRC-CIM-26-0304**  
  The carrier's own number for the carriage.
- `UUID` = **04bf0219-eb96-5f58-b434-f608b27f5387**  
  A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
- `VersionID` = **1**  
  The original, not a corrected version.
- `StatusCode` = **Issued**  
  The note is issued and in force.
- `IssueDate` = **2026-03-10**  
  Issued when the carrier takes over the loaded train.
- `IssueTime` = **11:35:00**  
  The time the sender's system issued the document, in the sender's local time.
- `Name` = **Rail consignment note under the CIM uniform rules**  
  The kind of transport document.
- `Description` = **The ore train from the mine siding to the factory.**  
  The carriage in words.
- `Note` = **Gatia dilobaa: labidria, dertrolvae, musgaor.** (languageID `qau`)  
  The note in Urvanian, the sender's language (world/countries.json): As the convention prescribes.
- `Note` = **Three originals: consignor, consignee, carrier.** (languageID `en`)  
  The same note in English, the working language between the countries: As the convention prescribes.
- `ShippingOrderID` = **VI-CS-26-0306**  
  The shipper's booking the carriage fulfils.
- `WaybillTypeCode` = **CIM**  
  The convention the document follows.
- `ConsolidatedIndicator` = **false**  
  One consignment, not a consolidation.
- `AdValoremIndicator` = **false**  
  No value declared to raise the carrier's liability.
- `OtherInstruction` = **Deliver against signature of the consignee.**  
  What the carrier must do at delivery.
