# Transport Execution Plan Request: Rinova Recovery to Fiumella Barges

*Example 3 of the flow "Recycled plastic granulate by river barge (Urvania → Bayvarra)" · [Transport Execution Plan Request in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-TRANSPORT-EXECUTION-PLAN-REQUEST-SCHEMA)*

Under CPT the waste processor is the transport user; it asks the barge operator for capacity down the river.

[The XML file](03-TransportExecutionPlanRequest.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.
