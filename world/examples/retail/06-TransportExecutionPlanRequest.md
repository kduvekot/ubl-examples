# Transport Execution Plan Request: Lumeway Distribution to Trasvia Haulage

*Example 6 of the flow "Distributor to retailer, delivered duty paid (domestic, Bayvarra)" · [Transport Execution Plan Request in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-TRANSPORT-EXECUTION-PLAN-REQUEST-SCHEMA)*

Because it sold DDP, the distributor books the outgoing truck from its distribution centre to the shop.

[The XML file](06-TransportExecutionPlanRequest.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

### The document itself

- `UBLVersionID` = **2.5**  
  The documents of the world use UBL 2.5.
- `CustomizationID` = **urn:ubl-examples:world**  
  The example world is a customization of UBL: it uses its own code lists for countries and currencies.
- `ID` = **LD-TR-26-0222**  
  The transport user's request number.
- `IssueDate` = **2026-04-25**  
  Because it sold delivered duty paid, the distributor books the truck.
