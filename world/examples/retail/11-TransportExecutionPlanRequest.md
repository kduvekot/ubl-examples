# Transport Execution Plan Request: Lumeway Distribution to Bayforth Forwarding

*Example 11 of the flow "Distributor to retailer, delivered duty paid (domestic, Bayvarra)" · [Transport Execution Plan Request in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-TRANSPORT-EXECUTION-PLAN-REQUEST-SCHEMA)*

Because it sold DDP, the distributor books the outgoing truck from its distribution centre to the shop.

[The XML file](11-TransportExecutionPlanRequest.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

  The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5 (world/ubl-versions.json); Party/AdditionalPartyIdentification first appears in UBL 2.5.
