# Catalogue Pricing Update: Lumeway Distribution to Brightmarket Stores

*Example 3 of the flow "Distributor to retailer, delivered duty paid (domestic, Bayvarra)" · [Catalogue Pricing Update in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-CATALOGUE-PRICING-UPDATE-SCHEMA)*

The distributor lowers the price of the spare side frame.

[The XML file](03-CataloguePricingUpdate.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

- `UBLVersionID` = **2.5**  
  The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5; Party/AdditionalPartyIdentification first appears in UBL 2.5.

  The Trade Accord's process profile the document belongs to: catalogue, a generic, versioned profile, not the flow; the run of the process is the ProfileExecutionID.

  This run of the process: the same in every document of the flow.

  The sender's number for this document.

  What the update is.

  The distributor lowers a price during the season.
- `IssueTime` = **13:10:00-01:00**

- `RevisionDate` = **2026-05-20**

- `RevisionTime` = **13:00:00**
