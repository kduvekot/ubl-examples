# Despatch Advice: Lumeway Distribution to Brightmarket Stores

*Example 7 of the flow "Distributor to retailer, delivered duty paid (domestic, Bayvarra)" · [Despatch Advice in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-DESPATCH-ADVICE-SCHEMA)*

The distributor announces the delivery and the truck that brings it.

[The XML file](07-DespatchAdvice.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

### The document itself

- `UBLVersionID` = **2.5**  
  The documents of the world use UBL 2.5.
- `CustomizationID` = **urn:ubl-examples:world**  
  The example world is a customization of UBL: it uses its own code lists for countries and currencies.
- `ID` = **LD-DA-26-0224**  
  The despatching party's number.
- `IssueDate` = **2026-04-29**  
  The day the truck was loaded at the distribution centre.

Inside `OrderReference`:
