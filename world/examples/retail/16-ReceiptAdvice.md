# Receipt Advice: Brightmarket Stores to Lumeway Distribution

*Example 16 of the flow "Distributor to retailer, delivered duty paid (domestic, Bayvarra)" · [Receipt Advice in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-RECEIPT-ADVICE-SCHEMA)*

[The XML file](16-ReceiptAdvice.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.
