# Invoice: Lumeway Distribution to Velumi Trading

*Example 19 of the flow "Overseas by container ship, cost insurance and freight (Bayvarra → island Lisavu)" · [Invoice in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-INVOICE-SCHEMA)*

Goods, sea freight and insurance (CIF) in one invoice; the receivable is sold to the factor, who is the payee.

[The XML file](19-Invoice.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

- `UBLVersionID` = **2.5**  
  The documents of the world use UBL 2.5.
- `CustomizationID` = **urn:ubl-examples:world**  
  The example world is a customization of UBL: it uses its own code lists for countries and currencies.
- `ID` = **LD-INV-26-0144**  
  The seller's invoice number.
- `IssueDate` = **2026-05-14**
