# Transport Service Description Request: Lumeway Distribution to Tidewell Ocean Lines

*Example 7 of the flow "Overseas by container ship, cost insurance and freight (Bayvarra → island Lisavu)" · [Transport Service Description Request in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-TRANSPORT-SERVICE-DESCRIPTION-REQUEST-SCHEMA)*

The distributor asks the ocean carrier for its sailings to the island.

[The XML file](07-TransportServiceDescriptionRequest.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

### The document itself

- `UBLVersionID` = **2.5**  
  The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5; Party/AdditionalPartyIdentification first appears in UBL 2.5.
- `CustomizationID` = **urn:ubl-examples:world:trns:transport-service-description:1.0#compliant#urn:ubl-examples:world:community:port-lumeport:1.0**  
  The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Transport service description"; the community specification "Lumeport port community". Each has a public description on the world's pages.
- `ProfileID` = **urn:ubl-examples:world:profile:transport:1.0**  
  The Trade Accord's process profile the document belongs to: transport, a generic, versioned profile, not the flow.
- `ProfileExecutionID` = **LMW-TX-26-0979**  
  The collaboration this document belongs to: Lumeway's request for Tidewell's description of its sea service. Lumeway Distribution started it and gave it this identifier, which every document of it repeats.
- `ID` = **LMW-TDR-26-0049**  
  The sender's number for this document.
- `UUID` = **85aef8c8-1b9f-512f-8ae1-044576d7ea15**  
  A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
- `IssueDate` = **2026-05-08**  
  Asked once the order is accepted.
- `IssueTime` = **14:00:00-01:00**  
  The time of the request; in the issuer's local time, with its offset from UTC.
- `Note` = **Weekly sailings to Selanu, please.**

- `ServiceInformationPreferenceCode` = **SCHEDULE** (listID `urn:ubl-examples:world:codelist:ServiceInformationPreferenceCode`)
