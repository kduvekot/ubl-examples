# Transport Service Description Request: Lumeway Distribution to Tidewell Ocean Lines

*Example 7 of the flow "Overseas by container ship, cost insurance and freight (Bayvarra → island Lisavu)" · [Transport Service Description Request in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-TRANSPORT-SERVICE-DESCRIPTION-REQUEST-SCHEMA)*

The distributor asks the ocean carrier for its sailings to the island.

[The XML file](07-TransportServiceDescriptionRequest.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.
