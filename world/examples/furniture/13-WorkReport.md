# Work Report: Brackenmere Furniture to Lumeport Public Works Department

*Example 13 of the flow "Furniture for the department store and for public offices (Bayvarra)" · [Work Report in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-WORK-REPORT-SCHEMA)*

The installers report the work done; the department approves it.

[The XML file](13-WorkReport.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

### The document itself

- `UBLVersionID` = **2.5**  
  The documents of the world use UBL 2.5.
- `CustomizationID` = **urn:ubl-examples:world**  
  The example world is a customization of UBL: it uses its own code lists for countries and currencies.
- `ID` = **BF-DOC-26-0579**  
  The sender's number for its work report.
- `IssueDate` = **2026-04-09**  
  Reported when the installation was finished.
