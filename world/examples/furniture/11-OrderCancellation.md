# Order Cancellation: Brightmarket Stores to Brackenmere Furniture

*Example 11 of the flow "Furniture for the department store and for public offices (Bayvarra)" · [Order Cancellation in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-ORDER-CANCELLATION-SCHEMA)*

With sales below the threshold, the store cancels the second delivery.

[The XML file](11-OrderCancellation.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

### The document itself

- `UBLVersionID` = **2.5**  
  The documents of the world use UBL 2.5.
- `CustomizationID` = **urn:ubl-examples:world**  
  The example world is a customization of UBL: it uses its own code lists for countries and currencies.
- `ID` = **BS-DOC-26-0577**  
  The sender's number for this document.
- `IssueDate` = **2026-04-22**  
  Cancelled the day after the exception notification.
- `CancellationNote` = **Sales of the line are below the agreed threshold; the second delivery is not needed.**  
  Why the order is cancelled.

### Order Reference

Inside `OrderReference`:

- `ID` = **BS-PO-26-0576**  
  The order cancelled.

### Buyer Customer Party

Inside `BuyerCustomerParty`:

- `Party/PartyIdentification/ID` = **20410411** (schemeID `urn:ubl-examples:world:XB:register`)  
  The party's preferred identifier: its number in the Federal business register of Bayvarra; identity of Brightmarket Stores (world/parties.json). Later mentions of the same party in this document repeat only this identifier and the name.
- `Party/PartyName/Name` = **Brightmarket Stores**  
  The trading name; identity of Brightmarket Stores (world/parties.json).
