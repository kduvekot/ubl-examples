# Order Response: Tostara Wood Modification to Marrowdale Sawmill

*Example 2 of the flow "Modification: bench slats modified under contract (Bayvarra → Urvania)" · [Order Response in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-ORDER-RESPONSE-SCHEMA)*

The plant accepts the job and plans its two kiln charges.

[The XML file](02-OrderResponse.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

### The document itself

- `UBLVersionID` = **2.5**  
  The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5; Party/ElectronicAddress first appears in UBL 2.5.
- `CustomizationID` = **urn:ubl-examples:world:trns:order-response:1.0**  
  The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Order response". Each has a public description on the world's pages.
- `ProfileID` = **urn:ubl-examples:world:profile:ordering:1.0**  
  The Trade Accord's process profile the document belongs to: ordering, a generic, versioned profile, not the flow.
- `ProfileExecutionID` = **MDS-TX-26-0047**  
  The collaboration this document belongs to: the sawmill's order of thermal modification from Tostara. Marrowdale Sawmill started it and gave it this identifier, which every document of it repeats.
- `ID` = **26-0014**  
  The seller's number for its response.
- `SalesOrderID` = **TWM-J-2526-014**  
  The plant's job number, as the order quotes it.
- `UUID` = **0ab1a768-2c83-5403-88ae-6a18d76ba5e5**  
  A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
- `IssueDate` = **2026-01-13**  
  The plant answers the next morning, when it has put the job into its kiln plan.
- `IssueTime` = **08:10:00-01:00**  
  Early, before the first load of blanks arrives; in the issuer's local time, with its offset from UTC.
- `OrderResponseCode` = **AP** (listID `UN/EDIFACT EDED 4343`)  
  UN/EDIFACT 4343 code AP: accepted, the order is accepted as it stands. The code is from the world's copy of UN/EDIFACT 4343 Response type: AP = Accepted.
- `Note` = **Job accepted. Kiln charges: 14 to 19 January (first load) and 21 to 26 January (second load); planing, sealing and bundling after each; the job is ready in store on 4 February.**  
  The plant's plan for the job, in words.
