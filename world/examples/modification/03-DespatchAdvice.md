# Despatch Advice: Marrowdale Sawmill to Tostara Wood Modification

*Example 3 of the flow "Modification: bench slats modified under contract (Bayvarra → Urvania)" · [Despatch Advice in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-DESPATCH-ADVICE-SCHEMA)*

The sawmill announces the first load of blanks on its own truck, with the lot, so the plant can check them in and keep them apart as the sawmill's goods.

[The XML file](03-DespatchAdvice.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

### The document itself

- `UBLVersionID` = **2.5**  
  The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5; Party/ElectronicAddress first appears in UBL 2.5.
- `CustomizationID` = **urn:ubl-examples:world:trns:despatch-advice:1.0**  
  The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Despatch advice". Each has a public description on the world's pages.
- `ProfileID` = **urn:ubl-examples:world:profile:despatch-receipt:1.0**  
  The Trade Accord's process profile the document belongs to: despatch and receipt, a generic, versioned profile, not the flow.
- `ProfileExecutionID` = **MDS-TX-26-0047**  
  The collaboration this document belongs to: the sawmill's order of thermal modification from Tostara. Marrowdale Sawmill started it and gave it this identifier, which every document of it repeats.
- `ID` = **MDS-DA-26-0051**  
  The despatching party's number.
- `UUID` = **c628c022-ea94-5fd7-82ae-452c5dbc3366**  
  A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
- `IssueDate` = **2026-01-13**  
  The day the first load leaves the sawmill.
- `IssueTime` = **08:10:00-01:00**  
  Sent by the despatch office when it opens at 08:00, the truck loaded and waiting to leave for the border; in the issuer's local time, with its offset from UTC.
- `DespatchAdviceTypeCode` = **DELIVERY** (listID `urn:ubl-examples:world:codelist:DespatchAdviceTypeCode`)  
  Advice of goods despatched for delivery. The code is from the Trade Accord's despatch advice type list: DELIVERY = Delivery.
- `Note` = **Please check the blanks on arrival and keep them apart as our goods; report any damage to our despatch office.**
