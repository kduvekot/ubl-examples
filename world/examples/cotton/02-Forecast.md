# Forecast: Lumeport Textile Mill to Selanu Cotton Ginnery

*Example 2 of the flow "Cotton: from the island's farms to the textile mill (Lisavu → Bayvarra)" · [Forecast in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-FORECAST-SCHEMA)*

The mill tells the ginnery how many bales it expects to buy this season.

[The XML file](02-Forecast.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

### The document itself

- `UBLVersionID` = **2.5**  
  The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5; Party/AdditionalPartyIdentification first appears in UBL 2.5.
- `CustomizationID` = **urn:ubl-examples:world:trns:forecast:1.0**  
  The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Forecast". Each has a public description on the world's pages.
- `ProfileID` = **urn:ubl-examples:world:profile:collaboration:1.0**  
  The Trade Accord's process profile the document belongs to: collaborative planning, a generic, versioned profile, not the flow; the run of the process is the ProfileExecutionID.
- `ProfileExecutionID` = **COTTON-2026-01**  
  This run of the process: the same in every document of the flow.
- `ID` = **LTM-FC-26-0192**  
  The mill's forecast number.
- `UUID` = **6810795c-6edd-5653-82dc-04180619e221**  
  A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
- `IssueDate` = **2026-02-02**  
  Sent before the harvest, when the crop's size can be judged, so the ginnery can plan its buying.
- `IssueTime` = **09:00:00-01:00**  
  The time is stated, because a revision refers to the forecast by its issue date and time; in the issuer's local time, with its offset from UTC.
- `Note` = **Depends on clothing orders from the store.**  
  What the forecast rests on.
- `VersionID` = **1**  
  The first forecast of the season.
- `BasedOnConsensusIndicator` = **true**  
  Agreed with the ginnery at the season meeting.
- `ForecastPurposeCode` = **ORDER** (listID `urn:ubl-examples:world:codelist:ForecastPurposeCode`)  
  A forecast of what the mill will order, so the ginnery can plan. The code is from the Trade Accord's forecast purpose list: ORDER = Order forecast.
