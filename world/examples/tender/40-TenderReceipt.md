# Tender Receipt: Lumeport Public Works Department to Brackenmere Furniture

*Example 40 of the flow "A public tender (Bayvarra)" · [Tender Receipt in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-TENDER-RECEIPT-SCHEMA)*

The authority acknowledges the furniture maker's first tender, with the time it was registered.

[The XML file](40-TenderReceipt.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.
