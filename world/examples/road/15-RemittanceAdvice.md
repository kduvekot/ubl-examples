# Remittance Advice: Lumeway Distribution to Valdara Industries

*Example 15 of the flow "Finished goods by truck across the land border (Urvania → Bayvarra)" · [Remittance Advice in the UBL 2.5 specification](https://docs.oasis-open.org/ubl/os-UBL-2.5/UBL-2.5.html#S-REMITTANCE-ADVICE-SCHEMA)*

The distributor announces the cross-border payment and which invoices it settles.

[The XML file](15-RemittanceAdvice.xml) is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

## Values and their reasons

- `UBLVersionID` = **2.5**  
  The documents of the world use UBL 2.5.

  The example world is a customization of UBL: it uses its own code lists for countries and currencies.
- `ProfileID` = **urn:ubl-examples:world:process:road**  
  The business process the document belongs to: the flow "Finished goods by truck across the land border (Urvania → Bayvarra)".
- `ProfileExecutionID` = **ROAD-2026-01**  
  This run of the process: the same in every document of the flow.
- `ID` = **LD-RM-26-0166**  
  The payer's remittance number.
