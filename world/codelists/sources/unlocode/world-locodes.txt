# A UN/LOCODE is the ISO 3166-1 alpha-2 country code and three characters for the place. The world's codes use the
# user-assigned country codes XU, XB and XL, which ISO 3166 never gives to a country: no entry of CL or AL has country
# XU, XB or XL, and CC lists only XZ ("Installations in International Waters") among the X codes. So no world code
# can be read as a real place. The three characters follow the place's name.
#
