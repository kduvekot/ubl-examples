Import Customs Declaration: Hafefo Fresh Produce to Island Customs Service

Document 9 of 12 in the flow Apples and pears in a reefer container by sea (Bayvarra → island Lisavu) · Import Customs Declaration in the UBL 2.5 specification

From Hafefo Fresh Produce to Island Customs Service, under the Trade Accord's transaction Import customs declaration.

← Invoice · all documents of the flow · Transportation Status →

The wholesaler lodges its import declaration before the ship arrives, so that the fruit is released when the reefer is discharged; the import consumption tax applies to food as to every import.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.
