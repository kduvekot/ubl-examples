Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5; the document type InvoiceStatusRequest first appears in UBL 2.5.
  • CustomizationID = urn:ubl-examples:world:trns:invoice-status:1.0
    The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Invoice status". Each has a public description on the world's pages.
  • ProfileID = urn:ubl-examples:world:profile:billing:1.0
    The Trade Accord's process profile the document belongs to: billing, a generic, versioned profile, not the flow.
  • ProfileExecutionID = 26-0416
    The collaboration this document belongs to: Velumi's order from Lumeway, with its change by air, from the order to the credit note. Velumi Trading started it and gave it this identifier, which every document of it repeats.
  • ID = LMW-ISR-26-0048
    The distributor's request number.
  • UUID = 6d87ab88-a921-5dfb-90cb-d87a8fcb59ec
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
  • RequestDate = 2026-05-29
    Two weeks after the invoice, without news from the buyer.
  • RequestTime = 10:00:00-01:00
    When asked; in the issuer's local time, with its offset from UTC.
  • Note = Has the invoice been approved?
    The question.

Sender Party

Inside SenderParty:

The party's own data, as Lumeway Distribution gives it (14 values)
  • PartyIdentification/ID = 20410274 (schemeID urn:ubl-examples:world:XB:register)
    The party's preferred identifier: its number in the Federal business register of Bayvarra. Later mentions of the same party in this document repeat only this identifier and the name.
  • AdditionalPartyIdentification/ID = 9520610900008 (schemeID GS1 GLN)
    A further identifier, the party's Global Location Number (the endorsed PartyIdentification holds one only): it identifies itself, its items and its places the GS1 way, under its company prefix, which starts with 952, the prefix GS1 reserves for examples .
  • PartyName/Name = Lumeway Distribution
    The trading name.
  • Language/ID = en (schemeID ISO 639)
    English, the language the party writes in this document. The code is from the world's copy of ISO 639 Language: en = English. An identifier that holds a code names the code's list in its schemeID.
  • Language/Name = English
    The language's name.
  • Language/LocaleCode = en-XB (listID urn:ubl-examples:world:codelist:LocaleCode)
    The English the party writes: the variety of Bayvarra, with the country as the region; English is used in all three countries, so its locale says which. The code is from the Trade Accord's locale list: en-XB = Bayvarran English.
  • Contact/Name = Accounts receivable
    The party's accounts receivable desk: the desk for its role in this document (it is owed the payment).
  • Contact/JobTitle = Credit controller
    The job of the person who answers at the desk.
  • Contact/Department = Finance
    The department the desk belongs to.
  • Contact/Telephone = +999 2 7121 955 964
    The party's switchboard, which puts the caller through to the desk. Telephone under +999, a country code the ITU reserves for a future global service (ITU-T E.164), so the number reaches no one; then the country digit and a number in Bayvarra's own plan: British-style closed numbering: always 10 digits after the country digit; the area code takes 2 to 5 of them (Lumeport 38, Upland State 7121, Gullhaven 38522 in the Northern Territory: the plan is national and does not follow state borders) and the trunk prefix 0 is dropped from abroad. Mobiles start with 7.
  • Contact/ElectronicMail = receivables@lumeway.example
    E-mail under the reserved .example domain (RFC 2606), so it cannot reach anyone.
  • Contact/Note = Weekdays 08:00–17:00
    When the desk can be reached.
  • ElectronicAddress/ExchangeNetworkID = urn:ubl-examples:world:network
    The network in which the address is registered: the world's own exchange network.
  • ElectronicAddress/ElectronicAddressID = XB:20410274 (schemeID urn:ubl-examples:world:endpoint)
    The party's electronic address in that network: its country code and its number in the Federal business register of Bayvarra. UBL 2.5 carries it here; Party/EndpointID is deprecated.

The same in every document Lumeway Distribution is named in.
