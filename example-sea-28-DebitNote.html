Debit Note: Velumi Trading to Lumeway Distribution

Example 28 of the flow "Overseas by container ship, cost insurance and freight (Bayvarra → island Lisavu)" · Debit Note in the UBL 2.5 specification

One pallet's heat-treatment mark was illegible, so customs inspected the container; the buyer debits the distributor in coral for the inspection and storage, a packaging fault on the seller's side.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.
