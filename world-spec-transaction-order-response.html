Order response

Transaction of the Trade Accord in the UBL example world · all specifications

Identifier: urn:ubl-examples:world:trns:order-response:1.0

One document type carries the transaction, the Order Response, which UBL 2.5 defines as follows: “A document used to indicate detailed acceptance or rejection of an Order or to make a counter-offer.”

Owner: Lumeport Trade Accord Council. Version 1.0.

Document types: OrderResponse.
