Waste Movement: Rinova Recovery to Environment Agency of Urvania

Example 2 of the flow "Production waste to recovery (domestic, Urvania)" · Waste Movement in the UBL 2.5 specification

The recovery facility reports to the environment agency the first load it has received under the notified stream: 54 bales, 22.9 tonnes net as its weighbridge found them, under the waste-stream number.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5 (world/ubl-versions.json); the document type WasteMovement first appears in UBL 2.5.
  • CustomizationID = urn:ubl-examples:world:trns:waste-movement:1.0
    The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Waste movement". Each has a public description on the world's pages (world/specifications.json).
  • ProfileID = urn:ubl-examples:world:profile:waste-shipment:1.0
    The Trade Accord's process profile the document belongs to: waste shipment, a generic, versioned profile, not the flow; the run of the process is the ProfileExecutionID.
  • ProfileExecutionID = WASTE-2026-01
    This run of the process: the same in every document of the flow.
  • ID = RR-DOC-26-0207
    The movement report number.
  • UUID = dbd3deda-0d71-53e4-9a07-a1f9d4add949
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
  • IssueDate = 2026-04-02
    Reported the day the load was received.
  • IssueTime = 11:45:00-01:00
    Once the truck had been weighed empty; in the issuer's local time, with its offset from UTC (D27).
  • WasteMovementTypeCode = RECOVERY (listID urn:ubl-examples:world:codelist:WasteOperationCategoryCode)
    The waste goes to recovery: Rinova recycles the film into granulate (operation R3 of its permit). The code is from the Trade Accord's waste operation category list: RECOVERY = Recovery.
  • SequenceNumberID = 1
    The first load of the stream.
  • ConsignmentQuantity = 12 (unitCode EA)
    Of about twelve notified.
