Invoice response

Transaction of the Trade Accord in the UBL example world · all specifications

Identifier: urn:ubl-examples:world:trns:invoice-response:1.0

The customer tells the supplier that it received, accepted or rejected an invoice, with an Application Response. (A message-level response, which says only whether a message could be processed, would be a transaction of its own.)

Owner: Lumeport Trade Accord Council. Version 1.0.

Document types: ApplicationResponse.
