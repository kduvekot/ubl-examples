Transportation Status: Ferrano Intermodal Hub to Ferrano Rail Cargo

Example 5 of the flow "Containers by rail under transit (Urvania → Bayvarra)" · Transportation Status in the UBL 2.5 specification

The intermodal terminal reports to the rail carrier that the containers are loaded on the train.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The documents of the world use UBL 2.5.
  • CustomizationID = urn:ubl-examples:world
    The example world is a customization of UBL: it uses its own code lists for countries and currencies.
  • ID = FIH-TS-26-0331
    The sender's status report number.
  • IssueDate = 2026-04-14
    Reported when the containers are on the train.
