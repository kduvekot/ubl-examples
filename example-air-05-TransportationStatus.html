Transportation Status: Lumeport Airport Cargo Terminal to Kelaro Air Cargo

Example 5 of the flow "An urgent part of the order by air (Bayvarra → island Lisavu)" · Transportation Status in the UBL 2.5 specification

The air cargo terminal reports the cargo accepted and built up for the flight.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The documents of the world use UBL 2.5.
  • CustomizationID = urn:ubl-examples:world
    The example world is a customization of UBL: it uses its own code lists for countries and currencies.
  • ID = LACT-TS-26-0326
    The sender's status report number.
  • IssueDate = 2026-05-13
    Reported when the cargo is built up for the flight.
