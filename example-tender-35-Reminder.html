Reminder: Valdara Industries to Lumeport Public Works Department

Example 35 of the flow "A public tender (Bayvarra)" · Reminder in the UBL 2.5 specification

The invoice is past due; the manufacturer reminds the department of the balance and charges Urvania's statutory interest.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5 (world/ubl-versions.json); Party/AdditionalPartyIdentification first appears in UBL 2.5.
  • CustomizationID = urn:ubl-examples:world:trns:reminder:1.0
    The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Reminder". Each has a public description on the world's pages (world/specifications.json).
  • ProfileID = urn:ubl-examples:world:profile:billing:1.0
    The Trade Accord's process profile the document belongs to: billing, a generic, versioned profile, not the flow; the run of the process is the ProfileExecutionID.

    This run of the process: the same in every document of the flow.
  • ID = VI-DOC-26-0224
    The manufacturer's reminder number.
  • UUID = 7f55c2fd-1414-5794-ab15-9ef94a32da95
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.

    Five days after the due date.
