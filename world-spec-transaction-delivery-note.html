Delivery note

Transaction of the Trade Accord in the UBL example world · all specifications

Identifier: urn:ubl-examples:world:trns:delivery-note:1.0

One document type carries the transaction, the Delivery Note, which UBL 2.5 defines as follows: “A document confirming the actual delivery of goods or services, detailing delivered items, quantities, and shipment information.”

Owner: Lumeport Trade Accord Council. Version 1.0.
