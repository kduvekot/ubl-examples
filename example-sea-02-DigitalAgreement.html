Digital Agreement: Lumeway Distribution to Velumi Trading

Example 2 of the flow "Overseas by container ship, cost insurance and freight (Bayvarra → island Lisavu)" · Digital Agreement in the UBL 2.5 specification

Before trading, the two parties join the multilateral digital agreement that fixes which UBL processes they use.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The documents of the world use UBL 2.5.
  • CustomizationID = urn:ubl-examples:world
    The example world is a customization of UBL: it uses its own code lists for countries and currencies.
  • ID = LD-DAG-26-0124
    The agreement's number.
  • IssueDate = 2026-05-05
    Signed before the first order.
  • VersionID = 1.0
    The first version of the agreement.
