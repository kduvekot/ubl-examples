Waybill: Ferrano Rail Cargo to Valdara Industries

Example 8 of the flow "Containers by rail under transit (Urvania → Bayvarra)" · Waybill in the UBL 2.5 specification

The rail consignment note goes to the transport user, now the seller.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.
