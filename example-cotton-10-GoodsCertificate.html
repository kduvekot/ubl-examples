Goods Certificate: Selanu Chamber of Commerce to Selanu Cotton Ginnery

Example 10 of the flow "Cotton: from the island's farms to the textile mill (Lisavu → Bayvarra)" · Goods Certificate in the UBL 2.5 specification

The island's chamber of commerce certifies the bales for export, at the ginnery's application.

The XML file is valid against the UBL 2.5 schemas and the world's code lists. Below, every value with its place in the document and the reason for it.

Values and their reasons

The document itself

  • UBLVersionID = 2.5
    The earliest version of UBL 2 that defines every element of the document, as UBLVersionID asks: computed from the published models of UBL 2.0 to 2.5 (world/ubl-versions.json); Party/AdditionalPartyIdentification first appears in UBL 2.5.
  • CustomizationID = urn:ubl-examples:world:trns:goods-certificate:1.0
    The specification the document follows, at each level it claims, chained with #compliant#: the Trade Accord's transaction "Goods certificate". Each has a public description on the world's pages (world/specifications.json).
  • ProfileID = urn:ubl-examples:world:profile🛃1.0
    The Trade Accord's process profile the document belongs to: customs, a generic, versioned profile, not the flow; the run of the process is the ProfileExecutionID.
  • ProfileExecutionID = COTTON-2026-01
    This run of the process: the same in every document of the flow.
  • ID = SCC-GC-26-0202
    The chamber's certificate number.
  • UUID = 78516adf-5718-5e78-bd9d-8e44536e335b
    A universally unique identifier of the document, derived from its place in the world (UUID version 5), so it stays the same on every build.
  • IssueDate = 2026-02-28
    Issued before shipment, at the ginnery's application.
  • IssueTime = 14:43:00
    The time the sender's system issued the document, in the sender's local time.
